✦ Interview Preparation

Crack Any Tech Interview

Real questions from top MNC interviews, explained clearly. Practice with our experts and walk in with full confidence.

☁️ Amazon Web Services
Intermediate
QWhat is the difference between S3 and EBS?
S3 is object storage accessible over the internet, ideal for static files and backups. EBS is block storage attached directly to EC2 for OS volumes and databases needing low-latency access.
QExplain VPC and its key components.
A VPC is an isolated virtual network in AWS. Key components include subnets (public/private), Internet Gateway, Route Tables, Security Groups, NACLs, and NAT Gateway for private subnet outbound traffic.
QWhat is Auto Scaling and how does it work?
Auto Scaling automatically adjusts EC2 capacity based on demand via min/max instance limits and scaling policies (CPU %, schedule, or custom metrics) to balance performance and cost.
🔷 Microsoft Azure
Intermediate
QWhat is Azure Resource Manager (ARM)?
ARM is Azure's deployment and management service. It provides a consistent layer to create, update, and delete resources via JSON/Bicep templates, enabling full Infrastructure as Code.
QDifference between Azure AD and on-prem Active Directory?
Azure AD is cloud-based using OAuth, SAML, and OpenID Connect. On-prem AD uses LDAP/Kerberos for domain-joined devices. Azure AD Connect syncs both environments.
QWhat are Availability Zones in Azure?
Physically separate datacenters within an Azure region with independent power, cooling and networking — providing 99.99% SLA for VMs against datacenter-level failures.
⚙️ DevOps Engineering
Advanced
QWhat is the difference between Docker and a VM?
Docker containers share the host OS kernel — lightweight (MBs, seconds to start). VMs include a full OS via a hypervisor — heavier (GBs, minutes to boot) but more isolated.
QExplain Kubernetes Pod, Deployment, and Service.
A Pod is the smallest deployable unit. A Deployment manages replicas and rolling updates. A Service provides stable networking via ClusterIP, NodePort, or LoadBalancer types.
QWhat is a CI/CD pipeline and its stages?
A CI/CD pipeline automates code integration and delivery. Typical stages: Source → Build → Unit Test → Integration Test → Staging Deploy → Approval → Production → Monitor.
🗄️ SQL & Databases
Beginner – Mid
QWhat is the difference between WHERE and HAVING?
WHERE filters rows before aggregation and cannot reference aggregate functions. HAVING filters groups after GROUP BY and can use aggregates like COUNT, SUM, and AVG.
QExplain Window Functions with an example.
Window functions (RANK, ROW_NUMBER, LAG, SUM OVER) perform calculations across related rows without collapsing them. Example: RANK() OVER (PARTITION BY dept ORDER BY salary DESC).
QWhat is indexing and when should you use it?
An index speeds up SELECTs via a lookup structure. Use on frequently filtered/joined columns. Avoid over-indexing — each index adds overhead to INSERT/UPDATE operations.
📊 Tableau Analytics
Beginner – Mid
QWhat are LOD expressions in Tableau?
LOD expressions (FIXED, INCLUDE, EXCLUDE) compute aggregations at a different granularity than the current view. Example: FIXED [Region] : SUM([Sales]) gives regional totals regardless of view filters.
QDifference between Extract and Live connection?
Live queries the source in real-time (always current, slower for large data). Extracts create a .hyper snapshot — faster performance but require scheduled refreshes to stay current.
QWhat are Sets vs Groups?
Groups combine members into static named categories. Sets are dynamic subsets based on conditions (top N, formulas) supporting IN/OUT logic, usable in calculations and as filters.
⚡ Power BI
Intermediate
QWhat is DAX vs Power Query M?
DAX is for calculations on loaded data (measures, calculated columns). Power Query M is used in the ETL phase to transform and shape data before loading into the model.
QStar schema vs snowflake in Power BI?
Star schema has a fact table with flat dimension tables (simpler, faster). Snowflake normalizes dimensions into sub-tables (compact but complex). Star schema is the Power BI best practice.
QWhat is CALCULATE in DAX?
CALCULATE evaluates an expression in a modified filter context — the most powerful DAX function. Example: CALCULATE(SUM(Sales), Region="North") returns North's total regardless of report filters.
